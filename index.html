GitHub connection setup

Connect to GitHub so dates save directly to the repo. One-time setup:

  1. Go to github.com/settings/tokens → Fine-grained tokens → Generate
  2. Name it anything (e.g. "Date Ideas")
  3. Set repository access to Only select repositories → pick Date-Ideas
  4. Under Permissions → Repository → Contents → set to Read and write
  5. Generate and paste the token below
